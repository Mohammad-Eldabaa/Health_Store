# Smart Clinic - Health Management App

A comprehensive healthcare application built with React Native that connects patients with medical services, featuring appointment booking, doctor profiles, first aid guides, medical articles, and patient management tools.
### website Demo: https://health-project-mu.vercel.app/

## Key Features

### Authentication
- **Login**: Easy login with gmail and password
- **Register**: Eesy Register and user receive and link in his gmail to active his account.
- **Forget password**: the user enter his email and recieve the link in his gmail then press it and enter a new password. 


### Patient Features
- **Appointment Booking**: Easy scheduling with healthcare providers
- **Medical Profile**: Secure storage of health history and records
- **First Aid Guide**: Step-by-step emergency instructions with videos
- **Medical Articles**: Educational health content library

### Doctor Features
- **Professional Profile**: Showcase credentials, certifications, and experience
- **Appointment Management**: View and manage patient bookings

### Nursing Staff Features
- **Patient Dashboard**: View all patients and their appointments
- **Medical Records**: Access and update patient health information

## Technology Stack

- **Frontend**: React Native (JavaScript)
- **Backend**: Supabase (Database + Authentication)
- **State Management**: (Zustand)
- **Navigation**: Stack navigation and Bottom curved bar navigatio
- **Video Handling**: React Native Video
- **Libraries**: SafeAreaView, MaterialIcon, expo/vector-icons, Zustand, formik, yup, react-native-curved-bottom-bar, react-native-picker/picker, async-storage/async-storage
